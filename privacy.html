Privacy Policy

Last updated: October 9, 2026

Video Studio ("the app") is a personal tool run by its owner on their own computer to manage their own YouTube channel. This policy explains what data the app touches and what it does with it.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • Google sign-in token for the owner's account, used only to upload, schedule and manage videos and comments on the owner's own channel.
  • The channel's own analytics: per-video view counts and average percentage watched.
  • Titles of the channel's own videos, to match analytics to videos.

The app does not access, collect or store data about viewers or any other YouTube users, and it does not read other people's comments.

How data is used

Analytics are used only to improve the channel's future videos. Nothing is sold, shared with third parties, or used for advertising.

Where data is stored

All data stays on the owner's own computer. The sign-in token is stored in a local file. No data is sent to any server operated by the app, because there is none.

Retention and deletion

  • Analytics are fetched fresh each day and are not kept beyond 30 days.
  • Access can be revoked at any time at Google security settings. Revoking access stops the app immediately, and the local token is deleted along with any stored API data within 7 days.
  • To request deletion of any data, email the contact address below.

Cookies

The app does not use cookies. This website does not use cookies or tracking.
